# 🇯🇵 일본 면세 계산기 (Japan Duty Free Calculator) 🇰🇷

일본 여행 시 복잡한 면세 혜택과 원화 환산 가격을 실시간 환율을 기반으로 한눈에 확인할 수 있는 간단한 웹 도구입니다.

## 주요 기능

-   **실시간 환율 반영**: Open Exchange Rates API를 통해 최신 JPY/KRW 환율을 실시간으로 가져옵니다.
-   **자동 면세 계산**: 일본의 면세 규정(세전 5,000엔 이상, 500,000엔 이하)을 자동으로 판별하여 면세 적용가를 계산합니다.
-   **간편한 입력**: 세금 포함 가격 또는 세전 가격 중 선택하여 입력할 수 있습니다.
-   **원화 환산**: 최종 면세 적용 금액(또는 비면세 금액)을 현재 환율에 맞춰 원화로 즉시 변환합니다.
-   **클립보드 복사**: 계산된 원화 금액을 클릭 한 번으로 클립보드에 복사할 수 있습니다.
-   **모바일 최적화**: 모바일 기기에서도 편리하게 사용할 수 있도록 반응형 디자인이 적용되었습니다.

## 사용 방법

1.  엔화(¥) 금액을 입력합니다.
2.  입력한 금액이 '세금 포함'인지 '세전'인지 선택합니다.
3.  하단에 표시되는 면세 적용 여부와 최종 원화 가격을 확인합니다.
4.  원화 가격을 클릭하여 금액을 복사할 수 있습니다.

## 최근 업데이트 (v1.1)

-   **계산 로직 개선**: 면세 한도(500,000엔) 초과 시 세금 포함 금액으로 정확히 계산되도록 수정했습니다.
-   **사용자 경험 향상**: 새로운 금액을 바로 입력할 수 있도록 입력창 클릭 시 기존 값이 초기화됩니다.
-   **안정적인 복사 기능**: 일부 환경에서 클립보드 복사가 되지 않는 문제를 해결하기 위해 안전한 폴백(Fallback) 방식을 적용했습니다.
-   **오류 대비**: 실시간 환율 API 호출 실패 시 기본 환율(9.0)을 적용하여 서비스가 멈추지 않도록 개선했습니다.

## 기술 스택

-   **Frontend**: React 19, TypeScript, Vite
-   **Styling**: Vanilla CSS (CSS Variables)
-   **API**: Open Exchange Rates (ER-API)

## 로컬 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build
```

## 면세 규정 참고
-   일본 면세는 보통 **동일 점포에서 하루 합계 세전 5,000엔 이상** 구매 시 적용됩니다.
-   소모품(식품, 화장품, 의약품 등)의 경우 최대 **500,000엔**까지만 면세 혜택을 받을 수 있습니다.
-   본 계산기는 일반적인 10% 소비세를 기준으로 계산합니다.
